# Third-party notices

OpsPilot implements its own procurement state machine, storage, policy checks and dashboard. The [LangChain React agent starter](https://github.com/langchain-ai/react-agent-js) was an architectural reference; LangChain and LangGraph are not dependencies of this application.

The application uses the [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk), [FastAPI](https://github.com/fastapi/fastapi), [Pydantic](https://github.com/pydantic/pydantic), HTTPX2 and Uvicorn. Their installed distributions retain their own copyright and license materials. Preserve those materials when redistributing dependencies. The application's own source is covered by [MIT](LICENSE).
